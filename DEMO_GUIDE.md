- [ ] Run `.\start-clawbot.ps1` and confirm the top header shows **`OPENCLAW LIVE`**.

- [ ] Click **`🙈 Hide Dog`** once before starting so Biscuit is genuinely hidden behind the sofa/far corner of the `15m × 11.5m` room.
- [ ] Set browser window to **1920×1080** (or **1440×900**) at 100% zoom, hide bookmarks bar, and confirm zero secrets are visible.
